# Talabat App Redesign — UI/UX Case Study

## Project Overview

This project focuses on redesigning the Talabat food delivery app to make the user experience clearer and easier.

## My Role

UI/UX Designer

## Tools

* Figma
* Miro

## Research and Design

* Conducted user research and stakeholder interviews.
* Analyzed 10 food delivery apps.
* Created a user persona, empathy map, and customer journey map.
* Organized the information architecture and user flows.
* Designed 17 app screens in Figma.
